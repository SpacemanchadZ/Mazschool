# MAZ School

Homeschool learning missions, hosted at https://mazschool.com with GitHub Pages.

## What's here

- `index.html` is the home page.
- `moon-bakery/` is the Moon Bakery Math mission (game and lesson guide).
- `assets/` has the logos and icons.
- `CNAME` tells GitHub Pages to use mazschool.com. Don't delete it.

## Adding a new mission

1. Make a new folder named after the mission, like `space-spelling/`, with an `index.html` inside.
2. In the home page `index.html`, copy the `<a class="mission">` block for Moon Bakery, paste it right after, and change the link, title, tags and description.
3. Commit. The site updates in a minute or two.
